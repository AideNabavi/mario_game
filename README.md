# 🍄 Mario Mushroom Runner

A classic 2D platformer inspired by the legendary Mario games, built with Python and Pygame.

## 🎮 About the Game

Jump into an exciting pixel-style adventure! Run through the level, collect coins, grab power-ups, avoid enemies, and reach the finish line.

## ✨ Features

- 🏃 Smooth player movement and running
- 🦘 Jumping and double-jump mechanics
- 🍄 Mushroom power-ups
- 🪙 Coin collection and scoring system
- 👾 Moving enemies and obstacles
- 🎵 Sound effects and background music
- ⏸️ Pause and resume functionality
- 🖥️ Fullscreen and windowed modes
- 🎯 Challenging platforming gameplay

## 🕹️ Controls

| Key | Action |
|---|---|
| `A` / `←` | Move left |
| `D` / `→` | Move right |
| `Space` | Jump |
| `Shift` / `X` | Run |
| `P` | Pause / Resume |
| `F11` | Toggle fullscreen |
| `Esc` | Quit the game |

## 🛠️ Built With

- Python
- Pygame

## 🚀 Installation

Make sure Python is installed on your computer.

Install Pygame:

```bash
pip install pygame
```

Run the game: 

```bash
python mushroom_runner.py
```
